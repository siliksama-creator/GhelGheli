# آموزشِ صوتیِ قلقلی — سمتِ اپ

همان تجربه‌ای که در وب منتشر شد، این بار داخلِ اپ. سه فایل:

| فایل | نقش |
|---|---|
| `tour_anchors.dart` | رجیستریِ `GlobalKey` + ویجتِ `TourAnchor` — آینهٔ `data-tour` وب |
| `tour_service.dart` | مدلِ بخش‌ها، `fetchTour`، `markTourSeen`، گذرگاهِ `TourBus` |
| `tour_overlay.dart` | پردهٔ تار، هاله، انگشت، کارت، پخشِ صدا |

## تصمیم‌هایی که نباید دوباره بحث شوند

1. **تور کلیک نمی‌کند.** همهٔ لمس‌ها را `Positioned.fill` + پرده می‌گیرد؛ وگرنه
   کاربر وسطِ آموزش وارد فروشگاه/بازی می‌شود و تور نصفه می‌ماند.
2. **صدا بعد از رسیدنِ انگشت شروع می‌شود.** مسیر: در (تبِ نوار پایین) → همان
   مسیری که کاربر می‌رفت → هدف → صدا. پس کلِ روایت صرفِ همان تکهٔ روشن می‌شود،
   نه صرفِ راه‌رفتن.
3. **افتِ محترمانه.** اگر لنگرِ یک بخش روی صفحه نباشد، کارت وسطِ قاب می‌ایستد
   و صدا پخش می‌شود. هیچ‌جای این پوشه `throw` ندارد.
4. **متن و ترتیب روی سرور.** `/api/onboarding` + صدای `/api/onboarding/audio/<file>`.
   کلاینت متن نمی‌سازد (`docs/live-config-contract.md`)؛ اصلاحِ یک کلمه نباید
   آپدیتِ اجباریِ اپ بخواهد.
5. **تورِ خودکار فقط از خانه.** اگر کاربر با لینکِ اتاقِ مشترک وسطِ بازی است،
   `_pendingAuto` نگه می‌دارد تا خودش به خانه برسد.
6. **هندسه پیش از نخستین `await`.** جای تب‌های نوار پایین در
   `didChangeDependencies` کشیده می‌شود؛ گرفتنِ `MediaQuery` بعد از `await`
   لینتِ `use_build_context_synchronously` را قرمز می‌کند.

## لنگرها

`TourAnchor(id: '…')` را دورِ خودِ ویجت می‌پیچند (دستی یا با ابزارِ
`tools/dart_wrap.py`). دو نوع لنگرِ بدونِ ویجت هم هست:

- `nav:x` — جای هندسیِ تبِ `x` در نوار پایین (پیش از `await` حساب می‌شود).
- `base#i/n` — قطعهٔ i از n قطعهٔ مساویِ لنگرِ `base`. برای تب‌های
  `SegmentedButton` که ویجتِ جدا ندارند، ولی عرضشان برابر است.

نقشهٔ id → فایل و آنچه باقی مانده: `docs/آموزش-صوتی-اندروید.md`.

## گارد

`backend/scripts/testOnboarding.js` (۵۷ بررسی) این‌ها را قفل می‌کند:
برابریِ دوطرفهٔ ۱۸ id سرور ⟷ نقشهٔ `TourPlan`، پوششِ مقصدها در نگاشتِ تبِ
پوسته، مسیرِ صدا زیرِ `/api`، «هر بخش دستِ‌کم یک لنگرِ موجود دارد»، «لنگرِ
بی‌مصرف نمانده»، شمارشِ `ButtonSegment` برای برشِ `#2/4`، ترازِ پرانتزِ همهٔ
فایل‌های Dart، و «پیچشِ سالمِ لنگر» (سرِ نامِ ویجت، نه سرِ پرانتز).

فلاتر روی هاستِ نصب نمی‌شود؛ تنها مرجع، ورک‌فلوی **Flutter Check** است و هر
هشدارِ analyze در آن قرمز می‌شود — پس صفر-هشدار بمانید.
