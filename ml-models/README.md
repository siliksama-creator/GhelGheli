# مدلِ بردارِ عصبیِ کارت (فاز ۲)

`card_embed_mobilenetv3.onnx` — استخراج‌کنندهٔ بردارِ ۱۲۸۰ بعدی برای تشخیص
هویتِ کارت.

- معماری: MobileNetV3-Large، فقط تنه (بدون سرِ طبقه‌بندی). ۴.۲M پارامتر، فایل
  ~۳۱۶ کیلوبایت — سبک برای اجرا روی گوشی (TFLite/ONNX-Runtime) و وب (ORT Web).
- ورودی: `input` با شکل `[batch,3,224,224]`، ترتیب کانال RGB، نرمال‌سازی:
  `x = (pixel/255 − mean)/std` با `mean=(0.485,0.456,0.406)`،
  `std=(0.229,0.224,0.225)`؛ برشِ مرکزی با `crop_pct=0.875` پیش از resize به ۲۲۴.
- خروجی: `embedding` با شکل `[batch,1280]`؛ پیش از ارسال به سرور، بردار
  L2-نرمال شود (سرور هم دوباره نرمال می‌کند).
- `EMBEDDING_VERSION = 1` در `backend/src/services/cardEmbedding.js` با این
  مدل/بُعد گره خورده. تعویضِ مدل = نسخهٔ جدید.

## نتایج PoC روی ۵۶ عکسِ واقعیِ کاتالوگ
- کارتِ کادرشده + تار/تیره/کج/فشرده: رتبه‌اول ۱۰۰٪، تأیید غلط ۰.
- عکسِ پرسپکتیو **روی میز بدون برش**: ۳۴٪ → فاز ۱ (برش پرسپکتیو) پیش‌نیاز.
- جفت‌های سختِ لایهٔ نام (هالند/هالند نقره‌ای، مارتینزها، جونیورها) با حاشیهٔ
  کافی تفکیک شدند.

جریان: کلاینت بردار را در فیلد `embedding` (آرایهٔ ۱۲۸۰ عددی) همراه ثبتِ عکس
می‌فرستد؛ مرجع‌ها با همین مدل از پیش ساخته شده‌اند.
