# حذف پنل ادمین از اپ موبایل — TODO و سند تصمیم

> سند برای ایجنت‌های بعدی: چرا این کار شد، چه چیزی تغییر کرد، و چه چیزی **نباید**
> دوباره ساخته شود. این فایل را قبل از دست‌زدن به روتینگ/ورود/بیلدِ موبایل بخوانید.

## تصمیم (خلاصه)
مدیریت پروژه فقط از **پنل وب ادمین** انجام می‌شود (`admin/`، آدرس
`admin.ghelghelishop.ir`). اپ موبایلِ منتشرشده **فقط کاربری** است؛ هیچ کد ادمینی
در آن کامپایل نمی‌شود. دلیل اصلی حجم نیست (حذف ~۴ مگ از Universal)، بلکه:

1. **امنیت:** اپِ استوری نباید کل سطح حملهٔ ۳۱ صفحهٔ مدیریتی + مسیر احراز ادمین را
   حمل کند.
2. **یک منبع حقیقت برای مدیریت:** به‌جای هم‌گام نگه‌داشتنِ «ادمین وب + ادمین
   اندروید»، فقط ادمین وب باقی ماند. پنل وب روی مرورگرِ گوشی هم باز می‌شود و
   جداگانه برای موبایل ریسپانسیو می‌شود (قدم بعدی، خارج از این سند).
3. **سادگی بیلد/تست** برای هم ما هم ایجنت‌ها.

## قاعدهٔ معماری (آینده)
- اپ موبایل = **فقط کاربر**. حتی اگر توکنِ ادمین در اپ ذخیره باشد، اپ **هرگز** وارد
  پوستهٔ ادمین نمی‌شود.
- پنل ادمین وب = **تنها** راه مدیریت (دسکتاپ و موبایلِ مرورگر).
- کد صفحات ادمین موبایل در ریپو **حذف فیزیکی** شده (`lib/screens/admin/`). اگر
  روزی اپ ادمینِ جدا لازم شد، از تاریخچهٔ گیت قبل از این کامیت برگردان و پشتِ فلگِ
  زمان‌بیلد بیاور؛ ولی پیش‌فرض «ساخته‌نشدن» است.
