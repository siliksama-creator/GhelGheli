# ۱. ⚽ فیزیک پنالتی — «به راست میزنیم به چپ میزنه»

## علت واقعی: باگ RTL، نه فیزیک

فیزیک کاملاً درست بود. مشکل **آینه‌ای بودن** بود:

کل اپ داخل `Directionality(textDirection: rtl)` است. یک `Row` معمولی این
جهت را به ارث می‌برد، پس فرزند اول در سمت **راست** رندر می‌شود.

شبکهٔ لمسیِ دروازه با `Row` ساخته شده بود:
```
for (var col = 0; col < 3; col++)   →  ناحیهٔ ۰ سمت راست
```

ولی نقاشِ زمین ریاضیِ چپ‌به‌راست دارد:
```
x = gl + gw * (col + 0.5) / 3       →  ناحیهٔ ۰ سمت چپ
```

**نتیجه:** کاربر گوشهٔ راست را لمس می‌کرد، ناحیهٔ ۰ ثبت می‌شد، توپ به
گوشهٔ **چپ** می‌رفت. دروازه‌بان هم آینه‌ای شیرجه می‌زد.

## رفع

شبکه صریحاً `TextDirection.ltr` شد. یک دروازهٔ فوتبال جهتِ متن ندارد؛
مختصاتش فیزیکی است. متن‌های صفحه بیرون این ویجت‌اند و RTL می‌مانند.

**۷ تست** که خودِ باگ را بازتولید می‌کنند: بدون تصریح جهت، شبکه آینه
می‌شود؛ با LTR، شبکه و نقاش هم‌جهت‌اند.

## تأیید فیزیک روی سرور زنده
```
حدس دقیق ناحیه ۸  → مهار ۱۱۹۵ از ۲۰۰۰
حدس گوشهٔ مخالف   → مهار  ۱۱۴ از ۲۰۰۰
✅ حدس دقیق ~۱۰ برابر بهتر از حدس غلط
```

# ۲. 🔴 کادر خالیِ بزرگ در گذر نبرد

## چطور پیدا شد: بایسکت دقیق

به‌جای حدس زدن، بخش‌ها را یکی‌یکی غیرفعال کردم:

| کاری که کردم | خطا |
|---|---|
| کل سربرگ غیرفعال | **۰** ← مقصر در سربرگ است |
| فقط `_PlusUpsell` غیرفعال | **۰** ← مقصر پیدا شد |

## علت

دکمهٔ «بازکردن» عرضِ **بی‌کران** می‌گرفت و پرتاب می‌کرد:
```
BoxConstraints forces an infinite width
```

ریشه: صفحه از `AnimatedSwitcher` در HomeShell، constraints شُل
(unbounded) می‌گیرد.

**چرا شبیه «باگ ظاهری» به‌نظر می‌رسید:** آن خطا رندرِ کل سربرگ را
می‌شکند. روی گوشیِ ریلیز خطاها پنهان‌اند، پس فقط یک کادرِ خالیِ بلند با
حاشیهٔ طلایی باقی می‌ماند — نه پیام خطایی، نه کرشی. دقیقاً اسکرین‌شات
شما.

## رفع + یک باگ دوم که همان تست گرفت

- دکمه عرض ثابت ۹۶ گرفت → هرگز بی‌کران نمی‌بیند
- **باگ دوم:** خانهٔ جایزه با ارتفاع ۶۲ وقتی برچسب دو خطی می‌شد
  («اسم آبی آسمانی» + «⭐ فقط پلاس») **۱۴ پیکسل سرریز** می‌کرد و نوار
  زرد-مشکی می‌آمد. به ۸۰ رفت.

**۸ تست جدید** که هر استثنای رندری را می‌گیرد.

# ۳. نوار بالا: حذف «سلام» + لوگوی درخشان

## حذف «سلام hotcat 👋»

دلیلش فقط سلیقه نبود: همان نام چند پیکسل پایین‌تر در هدر داشبورد هم بود،
پس **دو بار تکرار** می‌شد و جای نوار بالا را — که پنج آیکون مهم دارد —
تنگ می‌کرد. در اسکرین‌شات شما با «سلام h...» بریده شده بود.

`_profile` هم که تنها مصرف‌کننده‌اش همین بود، حذف شد.

## لوگوی درخشان

- هالهٔ رنگی که در **۳ ثانیه** آرام نفس می‌کشد
- حلقهٔ گرادیانِ رنگ برند دور لوگو

**چرا این‌قدر ملایم:** نوار بالا در **همهٔ** صفحه‌هاست. هر حرکتِ تند
اینجا در کل اپ آزاردهنده می‌شود. `RepaintBoundary` هم اضافه شد تا هر
فریمِ هاله، کل نوار را دوباره رنگ نکند.

**یکپارچه در وب و اندروید** — همان درخشش با CSS در وب.
