# باقی‌مانده‌ها و هاردکدها (به‌روز پس از a57c3ce + این پاس)

## انجام‌شده در این پاس
- راهنمای اسکرول انیمیشنی در **وب‌کاربر**، **ادمین وب**، **ادمین اندروید** + پوشش کامل‌تر تب‌های کاربر موبایل (قبلاً فقط بخشی از تب‌ها).
- ترتیب منوی ادمین اندروید = منوی ادمین وب (۲۲ بخش یکسان).
- دروازهٔ نسخهٔ وب از `/api/config` (force/min) تا آپدیت اجباری بدون ریلیز جدید قابل کنترل باشد.

## کاهش نیاز به آپدیت اپ (وضعیت فعلی)
این‌ها **بدون APK جدید** از سرور عوض می‌شوند:
- اقتصاد بازی، سکهٔ ضربه‌زن، سقف روزانه (`/api/config` + admin game-economy)
- بنر اعلان، ترتیب تب‌ها، maintenance، minVersion/forceUpdate
- کاتالوگ فروشگاه، پلاس، صندوق کارت، ماموریت‌ها، گذر نبرد، گردونه، لیگ
- لیدربورد و تنظیمات ادمین

برای تغییر UI/باگ کلاینت هنوز APK لازم است — این اجتناب‌ناپذیر است.

## هاردکد / fallback که هنوز مانده (کم‌خطر)
| مورد | کجا | توضیح |
|------|-----|--------|
| `59000` | `shop_page.dart` fallback قیمت پلاس ماهانه | فقط اگر API قیمت ندهد؛ بهتر است از bootstrap/shop فقط بیاید |
| `levelsPerDay = 2`, `tapCoinsPerLevel ?? 5` | tap config defaults | با پاسخ سرور override می‌شوند؛ fallback برای آفلاین |
| `APP_RELEASE` / `1.1.17` | home_shell / userweb | برای مقایسهٔ minVersion؛ باید با version واقعی بیلد هم‌خوان باشد |
| `TAP_CONFIG` در `tapGame.jsx` | منحنی/سقف | عمداً آینهٔ سرور است؛ منبع حقیقت سرور است ولی کپی کلاینت برای UX آفلاین مانده |
| آیکون‌ها/متن‌های UI | همه کلاینت‌ها | طبیعی است |

## اختلاف جزئی ادمین وب ↔ اندروید
- APIها از نظر قابلیت هم‌پوشانی دارند؛ تفاوت‌ها بیشتر در **قالب رشتهٔ URL** (template literal vs concatenation) است نه قابلیت غایب.
- برچسب وب «مانیتورینگ سرور» / موبایل همین؛ لیگ «لیگ ماهانه» یکسان شد.
- اگر قابلیتی فقط در یکی دیده شد، اولویت با **همان endpoint سرور** است — UI را باید در هر دو صدا بزند، نه منطق جدا.

## باگ‌های شناخته‌شده / ریسک
1. **ScrollHint روی window** در وب: اگر یک تب فقط داخل یک `overflow:auto` داخلی اسکرول شود (مثل چت)، ریل window ممکن است نشان ندهد — برای چت ارتفاع محدود است و کاربر اسکرول باکس را می‌بیند.
2. **content-area با max-height** در ادمین وب: اسکرول به ناحیهٔ محتوا منتقل شد تا ریل کار کند؛ اگر صفحه‌ای به اسکرول کل document وابسته بود باید چک چشمی شود.
3. **Push GitHub** فقط با PAT؛ توکن را rotate کنید.
4. **Invoicle** جدا است — دست نزنید.
